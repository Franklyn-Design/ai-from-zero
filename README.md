# AI From Zero

用普通人能听懂的语言，系统学习人工智能。

这是我的 AI 学习记录。我会从基础概念开始，逐步理解人工智能、机器学习、深度学习、大语言模型、提示词、RAG、Agent 以及 AI 应用开发。

这个项目既用于记录自己的学习过程，也希望能够帮助其他刚开始接触 AI 的人。

## 为什么创建这个项目

我已经会使用一些 AI 工具，但对 AI 背后的原理，以及怎样更有效、更可靠地使用 AI，还缺少系统性的理解。

因此，我决定通过以下方式学习：

> 学习一个概念 → 用自己的话解释 → 完成练习 → 整理成文章 → 分享并持续修正

## 学习原则

- 不只记住术语，也要理解背后的原理
- 尽量使用普通人能够理解的语言
- 每学习一个概念，都要配合实例和练习
- 不盲目相信 AI，重要信息必须验证
- 区分事实、推测和个人观点
- 保留参考资料并标明来源
- 允许理解不完整，也允许持续修正
